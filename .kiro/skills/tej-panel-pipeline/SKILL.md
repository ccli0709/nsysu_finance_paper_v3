# TEJ 面板資料處理管線（Panel Data Pipeline）

把 TEJ 下載的多份 CSV，一步步整併成可跑迴歸的研究樣本。程式以數字前綴命名，
**依序執行**即可；資料更新後，重新從 01 跑到最後一步即可重建所有輸出。

**研究主題**：企業水管理績效（水回收率／製程水回收率）與水資訊揭露（有無揭露）
對**成本黏性 (cost stickiness)** 的影響，以 TEJ 台灣製造業（排除金融保險業）為樣本。
理論與模型參考 `reference_paper/` 內兩篇文獻（第一篇低碳政策／綠色創新視角、
第二篇 ESG 資訊揭露視角），詳見 `study.md`。

## 執行順序

```
python 01_merge_tej_data.py          # 合併原始 zip/CSV → 01_merged_tej_data.csv
python 02_feature_engineering.py     # 變數建構        → 02_features_data.csv
python 03_sample_selection.py        # 樣本篩選+產業統計→ 03_sample_data.csv, 03_industry_stats.csv
python 04_build_model_variables.py   # 交乘項+建模變數  → 04_model_data.csv
python 05_run_regressions.py         # 成本黏性主模型   → 05_regression_results.txt, 05_regression_coef.csv
python 06_robustness_checks.py       # 穩健性檢定        → 06_robustness_results.txt, 06_robustness_coef.csv, 06_robustness_summary.csv
python 07_generate_paper.py          # 生成 Word 論文    → 水管理與成本黏性_論文.docx
```

需額外套件：`statsmodels`（OLS + 產業/年份固定效果 + 叢集穩健標準誤）、
`pypdf`（讀參考論文架構）、`python-docx`（產出 Word）。
安裝：`python -m pip install statsmodels pypdf python-docx`

命名慣例：`NN_描述.py` 產出 `NN_描述.csv`；下一步的輸入 = 上一步的輸出，
方便日後資料更新時「從頭依序重跑」。新增步驟就往後接 `05_`、`06_`。

## 環境

- Python 3.x + pandas、numpy。
- 原始資料放在 `tej_data/`，為 TEJ 匯出的 zip（內含單一 CSV）。

## 各步驟重點

### 01 合併（01_merge_tej_data.py）
- TEJ CSV 特性：**UTF-16 (LE, 含 BOM)、Tab 分隔**；「證券代碼」值形如
  `2201 裕隆`（代碼＋公司名稱，需以第一個空白拆開，只留代碼）。
- 面板頻率為**年度**，主鍵：**證券代碼 + 西元年份**。
- 三個資料集彙總為年度的方式不同（關鍵設計）：
  - **財務（單季）→ 年度**：年月前 4 碼為年份。
    - 流量變數（營業費用、推銷費用、管理費用、研究發展費、營業收入淨額）：
      **同年四季加總**為年度值（需該年四季齊全，否則標記缺值）。
    - 存量／比率變數（資產總額、員工人數-母公司、ROA、負債比率、總負債/總淨值）：
      **取年末 Q4（12 月）**該季值。
  - **水資源**：已是年度資料，直接以 [證券代碼, 年] 使用；若同年有多筆（序號），
    取有效值（非空）或首筆。
  - **ESG（年月 06/12）**：年月前 4 碼為年份，同年若有 06 與 12 兩筆，**優先取
    12（年末）**，否則取現有一筆。
- 合併：以 [證券代碼, 西元年份] 對財務與水資源做 outer join；ESG 的
  `SASB主產業` 視為公司靜態屬性（取各公司最新非空值），套用到該公司所有年份；
  ESG 的年度揭露欄（E_GRI_用水及廢水管理揭露度 等）以 [證券代碼, 年份] left join。
- 更新資料時：把新的 zip 檔名加入對應清單並註明頻率（單季/年度/年月）。

### 02 變數建構（02_feature_engineering.py）
延續成本黏性文獻（ABJ 模型）與 `study.md` 的變數設計：
1. 對每家公司依年份排序，計算前一年度值（t-1）。
2. **應變數與核心變數**：
   - ΔLNSGA = LN(本期營業費用) − LN(前期營業費用)。營業費用可直接取
     「營業費用」欄，或以「推銷費用＋管理費用」相加（提供參數切換）。
   - ΔLNREV = LN(本期營業收入淨額) − LN(前期營業收入淨額)。
   - D（收入下降虛擬變數）：本期營收 < 前期營收則為 1，否則 0。
3. **自變數（水管理）**：
   - `Water_Rate`（連續，主分析）：水回收率% 或 製程水回收率%（兩者皆保留，
     以參數擇一為主，另一作穩健性）。
   - `Water_Disc`（虛擬，次分析）：
     - 做法 A：該公司當年在水資源庫有「回收利用水量／水回收率」紀錄 = 1，否則 0。
     - 做法 B：ESG 的 E_GRI_用水及廢水管理揭露度 > 0 = 1，否則 0。
4. **控制變數**：
   - Size = LN(資產總額)。
   - AI（資產密集度）= 資產總額 / 營業收入淨額。
   - EI（員工密集度）= 員工人數-母公司 / 營業收入淨額。
   - ROA：取 ROA(A)稅後息前（或 ROA(C)，參數切換）。
   - Lev（財務槓桿）= 負債比率。
   - Decrease（連續兩年營收下降）：本期與前期皆 D=1 則為 1，否則 0。
5. 縮尾 Winsorize：對 ΔLNSGA、ΔLNREV、Water_Rate、AI、EI、ROA、Lev 等連續變數
   做前後 1%（`_w` 欄位），降低極端值影響。

### 03 樣本篩選 + 產業統計（03_sample_selection.py）
- 篩選（參數在檔案上方）：
  - 限定研究期間 `START_YEAR`~`END_YEAR`。
  - **排除金融保險業**（依 SASB主產業／交易所產業名為「金融」者剔除）。
  - 剔除 ΔLNSGA、ΔLNREV、D 任一缺值（迴歸必要欄）。
  - 剔除營收或營業費用 ≤ 0（無法取對數）者。
- 產出 `03_industry_stats.csv`：各產業（SASB主產業）的公司數、觀測數、
  有水資料筆數（Water_Rate 非空）、有揭露筆數（Water_Disc=1）、
  迴歸可用筆數，**用來檢視各產業樣本充足度與揭露比例**。

### 04 建模變數（04_build_model_variables.py）
- 建立成本黏性模型所需的**交乘項**：
  - `D×ΔLNREV`（捕捉整體成本黏性，係數 β2 預期為負）。
  - `Water_Var×D×ΔLNREV`（三重交乘，核心係數 β3）：
    - 主分析代入 `Water_Rate`；次分析代入 `Water_Disc`。
  - 各控制變數與 `D×ΔLNREV` 的交乘（Controls×D×ΔLNREV），依 ABJ 慣例納入。
- 產業（SASB主產業）與年份轉為虛擬變數群（固定效果）。
- 欄名含 `%`、空白、`×`、`Δ` 等字元會先安全化（如 `Water_Rate`、`D_x_dREV`），
  並保留原始名對照表，供後續 statsmodels 與論文對表使用。

### 05 實證迴歸（05_run_regressions.py）
- 方法：**OLS（pooled）+ 產業與年份固定效果（虛擬變數）+ 公司叢集穩健標準誤**
  （cluster by 證券代碼），為成本黏性文獻標準設定。
- 主模型（對應 study.md）：
  ```
  ΔLNSGA = β0 + β1·ΔLNREV + β2·(D×ΔLNREV) + β3·(Water_Var×D×ΔLNREV)
           + β4·Water_Var + Σ Controls×D×ΔLNREV + Σ Industry + Σ Year + ε
  ```
- 兩組主結果：
  - 模型 1（主分析）：Water_Var = `Water_Rate`（水回收率% 或 製程水回收率%）。
  - 模型 2（次分析）：Water_Var = `Water_Disc`（揭露虛擬變數）。
- 係數解讀：
  - β2 < 0 且顯著 → 樣本存在成本黏性。
  - β3（H1）：Water_Rate 之 β3 顯著為**負** → 水回收績效**加劇**黏性。
  - β3（H2）：Water_Disc 之 β3 顯著為**正** → 水資訊揭露**緩解**黏性。
- 結果檔附安全欄名對照表；N 取自實際迴歸樣本（去除任一缺值後）。

### 06 穩健性檢定（06_robustness_checks.py）
- 輸入回到 `03_sample_data.csv`（全製造業樣本），以便切換衡量與擴充樣本。
- 穩健性維度（每個維度重跑主模型並輸出跨設定對照表 `06_robustness_summary.csv`，
  含顯著性星號）：
  1. **水績效衡量替換**：水回收率% ↔ 製程水回收率%。
  2. **揭露定義替換**：做法 A（有水量紀錄）↔ 做法 B（GRI 揭露度 > 0）。
  3. **營業費用定義替換**：營業費用欄 ↔ 推銷費用＋管理費用。
  4. **產業樣本維度**：全製造業 ↔ 限定水資料充足產業。
- 目的：確認核心係數 β3 的方向與顯著性在不同衡量／樣本下穩健。

### 07 生成 Word 論文（07_generate_paper.py）
- 參照 `reference_paper/` 之範例論文 PDF 架構：中文摘要 / Abstract / 第一章 緒論 /
  第二章 文獻探討（含 H1–H2，對應綠色投資調整成本與資訊透明度兩機制）/
  第三章 研究方法（資料、變數定義表、成本黏性模型）/
  第四章 實證結果（敘述統計、相關矩陣、模型 1/2 迴歸表、穩健性）/
  第五章 結論與建議 / 參考文獻。
- 敘述統計與相關矩陣由 `04_model_data.csv` 即時計算；迴歸表係數／t 值／顯著性
  星號直接讀自 `05_regression_coef.csv` 與 `06_robustness_coef.csv`，確保與分析
  結果一致。
- 注意：coef CSV 的變數為安全欄名（如 `Water_Rate`、`D_x_dREV`），對表時用安全名；
  另附原始名對照。迴歸表的 N 取自實際迴歸結果，非全樣本。

## 已知資料特性 / 注意事項

- **頻率不一致**：財務為單季、水資源為年度、ESG 為 06/12 年月；01 步驟統一彙總為
  年度是整條管線的關鍵前提（流量加總、存量取年末）。
- **產業別來源**：三個 zip 中僅 ESG 資料集含 `SASB主產業`；視為公司靜態屬性套用。
  未被 ESG 資料集涵蓋的公司會缺產業別，於 03 篩選時一併檢視。
- **揭露偏少 / 不平衡面板**：有水資料（Water_Rate 非空）的公司相對少；主分析
  (Water_Rate) 樣本較小，次分析 (Water_Disc) 可涵蓋全樣本（未揭露=0）。
- **GDP 成長率等總體控制**：不在 TEJ zip 內；年份固定效果已吸收年度總體效果，
  故可不另外納入外部總體變數（如需仍可外掛年度 GDP）。
- 取對數前需確保營業費用、營業收入淨額為正值；負值或零值於 03 剔除。

## 換主題 / 換資料時如何沿用

1. 把新的 TEJ zip 丟進 `tej_data/`，在 01 登記檔名並註明頻率（單季/年度/年月）與
   欄位；單季財務記得設定流量欄（加總）與存量欄（取年末）清單。
2. 若主鍵欄名不同（只有「年」或「年月」），01 已自動判斷年份擷取方式。
3. 調整 02 的變數建構清單（應變數、水管理衡量、控制變數）、03 的篩選參數
   （期間、排除產業）、04 的交乘項與固定效果設定、05/06 的模型與穩健性維度。
4. 從 `01` 依序重跑到最後一步。
